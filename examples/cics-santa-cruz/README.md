# CICS Santa Cruz website

A standalone React and Vite website for the College of Information and Computing Sciences at Marinduque State University, Santa Cruz Campus.

## Run locally

From this directory:

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Pages

- `/` — Home
- `/about` — About CICS
- `/programs` — BS Information Systems
- `/faculty` — College structure, Dean, OJT coordinators and faculty
- `/admissions` — Official admissions information
- `/contact` — College contact details

The site uses the MarSU seal from the source website and links to official university and college resources. The faculty and coordinator names are attributed to the university's CICS OJT coordination page.
